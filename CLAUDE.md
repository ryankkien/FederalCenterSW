# CLAUDE.md

Follow the repository guidance in `AGENTS.md`.

Before designing or building contract data models, report intake, document processing,
contract views, dashboards, or insight workflows, read `docs/product.md`. That file
describes future product capabilities and should be treated as the planning direction,
not as a list of features that already exist.

Keep product notes in `docs/product.md` so Claude, Codex, and human contributors share
one source of truth.
